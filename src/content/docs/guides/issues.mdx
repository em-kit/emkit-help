Issues offers a task management system to track progress on things that are not handled in services like Jira or Linear (e.g. your tasks as manager, team member action items discussed during 1:1s, ...).

Issues have the following properties:
- **Status** — To Do, In Progress, Done
- **Priority** — Urgent, High, Medium, Low (optional)
- **Assignee** — Yourself (Me) or a team member
- **Due date** — Optional target date
- **Description** — Rich markdown editor
- **Sub-issues** — Break work into smaller pieces

## List and Kanban views

Switch between **List** and **Kanban** views using the toggle in the top-right corner.

- **List view** — Issues grouped by status with collapsible sections
- **Kanban view** — Drag-and-drop cards between To Do, In Progress, and Done columns

## Filters

Filter issues by:

- **Status** — Show only specific statuses
- **Priority** — Show only specific priorities
- **Assignee** — Filter by Me or a specific team member

## Creating an issue

Click **New Issue** to open the creation modal:

1. Enter a title
2. Optionally add a description, status, priority, assignee, and due date
3. Click **Create issue**
4. Toggle **Create more** to stay in the modal for rapid entry

## Editing an issue

Click any issue to open the detail drawer where you can edit all fields, manage sub-issues, and delete the issue.

## Ask Copilot on an issue

The issue drawer has an **Ask Copilot** button in the top-right corner. Click the dropdown arrow to pick which [agent](/guides/copilot/agents/) should answer — the default agent is marked. Selecting an agent inserts an `@`-mention into a new comment; type your question and post the comment.

The mentioned agent reads the issue's title, description, sub-issues, and prior comments, then posts its reply directly in the comment thread. Mention an agent again in any follow-up comment to keep the conversation going.

## Action items in 1:1s

Issues are also used as action items in 1:1 meetings. When you add an action item during a 1:1, it creates an issue linked to that meeting. Open issues from previous 1:1s are carried forward automatically.
